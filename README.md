# fleet-deck

Local ledger and dashboard of every AI agent, model, token and cost on your machine.

Run `npx fleet-deck` to scan the local agent logs and open the dashboard on localhost.

## Install

```sh
npx fleet-deck          # scan local agent logs, then open the dashboard
```

Requires Node.js 22.13 or newer (uses the built-in `node:sqlite` module; on Node
22.5-22.12 run with `node --experimental-sqlite`).
